Tujuan aplikasi

Mengembalikan proses berpikir ke tangan siswa

Di era kecerdasan buatan, jawaban jadi mudah didapat, tetapi pemahaman tidak bisa disalin. DeepMentor AI dibuat agar siswa tetap berlatih bernalar: menjelaskan, menganalisis, dan menyimpulkan dengan caranya sendiri.

Bagi guru, aplikasi ini mengubah tugas menjadi percakapan belajar yang terukur. Setiap jawaban dinilai, dijelaskan, dan dicatat sehingga guru melihat proses siswa, bukan hanya hasil akhirnya.

Guru membuat kelas dan membagikan kode akses, siswa masuk ke kelas dengan kode tersebut, dan semua nilai tercatat dalam laporan.

Pertanyaan yang sering diajukan

Bagaimana siswa masuk?

Ketik email (username) dan password yang dibuat saat mendaftar. Setelah masuk, pilih menu "Masuk Kelas Baru" dan masukkan kode akses 6 karakter dari gurumu. Kelas dan tugas dari guru akan muncul di dashboard, lalu mulai diskusi.

Mengapa tahapku terkunci?

Setiap tahap butuh kualitas jawaban minimal 80%. Jawaban yang singkat, tidak nyambung, atau tanpa alasan akan membuat tahap tetap terkunci. Baca Penjelasan Mendalam Mentor, lalu perbaiki jawabanmu.

Apa itu Penjelasan Mendalam Mentor?

Setelah setiap jawaban, Mentor menjelaskan bagian yang sudah tepat, bagian yang perlu diperkuat, kaitannya dengan 8 Dimensi Profil Lulusan dan 7 Kebiasaan Anak Indonesia Hebat, serta langkah berikutnya.

Mengapa pesanku ditolak?

Pesan ditolak bila berisi tempelan teks panjang (copy-paste), pola kalimat khas mesin AI, atau bahasa kasar. Tulis dengan kata-katamu sendiri dan gunakan bahasa yang sopan. Teguran dicatat pada laporan guru.

Bagaimana guru membuat tugas?

Masuk lewat halaman login memakai email (username) dan PIN (akun guru dikenali otomatis), buka tab Setup Materi, isi acuan kompetensi, studi kasus, dan media (YouTube, gambar, audio), lalu terbitkan. Pantau nilai lewat tombol Monitoring & Laporan Kelas pada kartu kelas di tab Daftar Kelas.

Lupa PIN guru?

Klik "Lupa password / PIN?" pada halaman login, masukkan email akunmu, lalu buat PIN baru.

Bagaimana mengunggah ke hosting?

Aplikasi ini dipasang ke Vercel (lihat README-VERCEL.md). Setiap perubahan yang di-push ke GitHub akan otomatis ter-deploy. API Key Gemini diatur lewat Environment Variable di Vercel.

Lupa PIN / Password

Masukkan email yang kamu pakai saat mendaftar. Kami akan mengirim kode untuk membuat password baru.

Kode berlaku 30 menit. Jika email tidak masuk, periksa folder spam.

Konfigurasi Gemini API & Panduan Hosting Sendiri

Siap di-upload ke cPanel, Hostinger, Niagahoster, Vercel, atau VPS sekolah

1. Google Gemini API (Aman, lewat Server)

API Key tidak lagi disimpan di browser maupun di kode halaman. Key diatur di server lewat Environment Variable GEMINI_API_KEY di Vercel, dan semua permintaan AI dilewatkan melalui api/gemini.

Memeriksa koneksi AI server...

2. Cara Memasang & Memperbarui di Vercel

  1. Push seluruh isi proyek ke repositori GitHub (privat disarankan), lalu Import Project di Vercel.
  2. Database: buat database PostgreSQL (mis. Neon lewat Vercel Storage), lalu jalankan isi database/schema.sql di SQL Editor.
  3. Isi Environment Variables di Vercel: DATABASE_URL, SESSION_SECRET, dan GEMINI_API_KEY, lalu Redeploy.
Catatan keamanan: API Key hanya ada di server (Environment Variable Vercel, tidak bisa dibuka dari web). Batasi kuota key di Google AI Studio / Cloud Console. Data guru, siswa, dan nilai tersimpan di database PostgreSQL (DATABASE_URL, juga hanya ada di server). Password disimpan sebagai hash, bukan teks asli.
